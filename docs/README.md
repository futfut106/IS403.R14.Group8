# Tài liệu hướng dẫn và quản lý triển khai

Chứa tài liệu giúp thành viên theo dõi phạm vi, cách chạy và mối liên hệ giữa báo cáo với sản phẩm trong repo. Hiện chưa chuyển các tài liệu chi tiết vào repo mới.

| Tài liệu dự kiến | Vai trò |
|---|---|
| `repository_file_mapping.md` | Mapping file hiện có/cần bổ sung vào cấu trúc đích |
| `report_code_mapping.md` | Mục/bảng/hình báo cáo → code/lệnh → input → output |
| `data_dictionary.md` | Định nghĩa biến, đơn vị, cấp quan sát và quy ước giá trị thiếu/0 |
| `run_guide.md` | Môi trường, chuẩn bị dữ liệu, thứ tự và lệnh chạy thực tế |
| `action_plan.md` | Kế hoạch hoàn thiện, việc còn thiếu và trạng thái thực hiện |

Danh sách trên là tài liệu sẽ được bổ sung, chưa phải các liên kết tải được. Cập nhật chúng khi thay đổi đường dẫn, schema, chương trình hoặc bố cục báo cáo. Không giữ hướng dẫn theo số mục cũ nếu không còn áp dụng.
