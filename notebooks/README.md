# Notebook phân tích

Thư mục dành cho các file Jupyter `.ipynb` trình bày các bước phân tích, bảng, hình và diễn giải kết quả. Hiện chưa bổ sung notebook.

Các nhóm nội dung dự kiến:

- Thống kê mô tả đặc điểm xe và địa bàn.
- Kiểm định H1–H4 và phân tích độ nhạy.
- Phân tích chuỗi thời gian và chẩn đoán.
- Trình bày kết quả dự báo và so sánh mô hình.

Notebook gọi lại các hàm trong `source/`, tránh duy trì một phiên bản thuật toán riêng khác với mã chạy chính. Tên notebook theo nội dung; khi bổ sung sẽ ghi rõ đầu vào, môi trường và thứ tự chạy.
